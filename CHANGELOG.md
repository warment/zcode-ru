# Changelog

## v2.0.3 — 2026-09-04/05

- **Первый внешний контрибьютор: @Ruzibekov** — 73 правки платёжной терминологии + тестовый набор (`tests/`, node:test: плейсхолдеры, дубликаты, рендер плюралов 0/1/2/4/5/11/21/101) + фикс install.ps1 (BOM для PowerShell 5.1, русские сообщения). Принято cherry-pick с сохранением авторства

- **Фикс меню-бара macOS:** верхняя строка меню (Файл/Правка/Вид/Окно/Справка), dock и tray оставались китайскими. Причина: у апстрима словарь меню `sp` в `chunk-47DZU7O5.js` содержит только `zh-CN`/`en-US` с fallback на **zh-CN** — при `locale: ru-RU` резолвер `sp["ru-RU"]` давал undefined и брал китайский. Добавлен третий словарь `ru-RU` (52 ключа: меню, статусы обновлений, dock, tray)
- Порядок обновления зафиксирован: **сначала обновление ZCode, потом русификация** (extract → check → build → apply)

## v2.0.2 — 2026-09-04 (инфраструктура)

- **Gate в сборке:** `build.mjs` сам прогоняет `check.mjs --strict` до распаковки asar — невалидный словарь больше не доходит до патчей (exit 1 с внятной причиной)
- **Плюральная валидация в check.mjs:** у каждой ICU-базы корпуса (18 баз, суффиксы `.one/.other/.many`) покрыты все суффиксы; одинаковые ru-формы при разных en — warning; скобочные формы «файл(ов)» — error
- **`--plurals-report`:** отчёт по ~196 счётным строкам без ICU-суффиксов (en→ru) для ручной вычитки число-нейтральности
- **Спайк плюрального рантайма:** ICU MessageFormat / `Intl.PluralRules` апстримом не используются — выбор ключа тернарником `count === 1 ? .one : .other` (для 3 баз — `.many`); формы 2–4 рендерятся через `.other/.many`, категории `.few` в корпусе нет. Задокументировано в глоссарии
- mtime-предупреждение: корпус старше установленного app.asar → напоминание про `npm run extract`

## v2.0.0 — 2026-08-30

Нативная локаль ru-RU для ZCode **3.10.1** (build 6272) — полная переработка пакета.

- Третий язык в селекторе: System / English / **Русский** (китайский не затронут)
- **5 018 ключей** — 100% корпуса рендерера (чат, настройки, плагины, скиллы, MCP, субагенты, git, автоматизации, usage…)
- Fallback на английский для строк будущих версий апстрима — «голых» ключей не бывает
- Переведены описания встроенных агентов и стилей вывода (host-чанк, 5 строк)
- Переведены мелкие окна: мониторинг процессов, панель разрешений Computer Use
- Автодетект системной русской локали
- `install.sh` — установка одной командой с бэкапом, проверкой версии и автооткатом; `--restore` для отката
- Глоссарий терминов, тон «вы», унификация терминологии (папка/каталог, тариф, промпт)
- Валидатор `check.mjs --strict` (полнота, плейсхолдеры, мусор) — готов для CI
